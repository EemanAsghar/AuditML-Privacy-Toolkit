audit.py
import auditml

# Split your training set into members / non-members
member_loader, nonmember_loader = auditml.split_loaders(train_dataset)

# Audit — works with any nn.Module
results = auditml.audit(model, member_loader, nonmember_loader)

print(results.summary())

How it works

From model to privacy report
in three steps.

No config files. No boilerplate. Bring your model and your data — AuditML handles the rest.

01 — Train
🧠

Train your model

Use any PyTorch architecture. CNN, ResNet, Transformer — if it's an nn.Module, it works.

model = MyCNN()
# your training loop here
02 — Audit
🔍

Run the audit

Pass your trained model and two data loaders. Choose which attacks to run, or run all four at once.

results = auditml.audit(
  model, members, nonmembers
)
03 — Report
📊

Get your report

AUC-ROC, TPR@1%FPR, accuracy — per attack. An interactive HTML report opens automatically in your browser.

results.report("./out", open_browser=True)
Privacy Attacks

Four attacks. One unified API.

Each attack exposes a different kind of leakage. Run them all or pick only what you need.

Fast · seconds

Threshold MIA

Classifies training members vs non-members by thresholding the model's loss or confidence. The fastest attack — a strong privacy baseline.

White-box Loss / confidence
Powerful · minutes

Shadow Model MIA

Trains shadow models with known membership labels, then trains an MLP attack classifier on their outputs. The strongest known MIA.

Black-box Output distribution
Visual · gradient

Model Inversion

Reconstructs representative training images by optimising in pixel space via gradient descent. Exposes what the model has memorised.

White-box Gradients + TV loss
Sensitive attribute

Attribute Inference

Predicts sensitive group membership from softmax outputs — revealing whether the model leaks protected attributes about individuals.

Black-box Softmax outputs

full_example.py
import auditml

# Split dataset → members / non-members
m, nm = auditml.split_loaders(train_dataset)

# Run all attacks
results = auditml.audit(model, m, nm)

# Access results
results["mia_threshold"].auc_roc # → 0.641
results.is_vulnerable() # → True

# Save / reload without re-running
results.save("results.json")
r2 = auditml.AuditResults.load("results.json")
