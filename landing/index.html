How it works

From model to privacy report
in three steps

No config files. No YAML. No custom dataset wrappers. Bring your model and your data — AuditML handles the rest.

01
🧠

Train your model

Use any PyTorch architecture you want. AuditML doesn't care about CNN vs ResNet vs Transformer — if it's an nn.Module, it works.

model = MyCNN()
model.train()
# ... your training loop
02
🔍

Run the audit

Pass your trained model and two data loaders — one of samples it trained on, one it didn't. Choose which attacks to run or run all four.

results = auditml.audit(
  model, members, nonmembers
)
03
📊

Get your report

Accuracy, AUC-ROC, TPR@1%FPR, and more — per attack. See which attacks worked, how bad the leakage is, and what to do about it.

results["mia_threshold"].auc_roc
results.most_vulnerable()
results.is_vulnerable()
Privacy Attacks

Four attacks. One unified API.

Each attack exposes a different kind of privacy leakage. Run them all at once or pick only the ones you need.

🎯
Fast · seconds

Threshold Membership Inference

Classifies training members vs non-members by thresholding the model's prediction confidence on the true label. The fastest attack — a strong privacy baseline in seconds.

Type:White-box
Signal:Loss / confidence
👥
Powerful · minutes

Shadow Model MIA

Trains multiple shadow models that mimic the target, generating (output, membership) pairs to train an MLP attack classifier. The most powerful known membership inference attack.

Type:Black-box
Signal:Output distribution
🖼️
Visual · white-box

Model Inversion

Reconstructs representative training images by optimising in pixel space via gradient descent. Exposes what the model has memorised about each class visually.

Type:White-box
Signal:Gradient + TV loss
🔍
Sensitive attribute

Attribute Inference

Trains an attack model on softmax outputs to predict sensitive group membership — revealing whether a model leaks protected attributes about individuals in its training data.

Type:Black-box
Signal:Softmax outputs
Differential Privacy

Found leakage? Fix it too.

AuditML includes DP training via Opacus. Train with privacy guarantees, then re-run the attacks to measure the exact reduction in leakage.

📉

Measure leakage

Run all four attacks on your baseline model. See exactly which attacks succeed and by how much.

🛡️

Train with DP

Enable DP in the config and train a privacy-preserving model with a target ε using Opacus under the hood.

📊

Compare results

The report shows attack accuracy and AUC-ROC for both models side by side with the privacy–utility tradeoff.

Install with pip, import, and call auditml.audit() on your model. No account, no API key, no signup.

pip install auditml

Requires Python 3.10+ and PyTorch 2.1+.

full_example.py
import auditml
from torch.utils.data import DataLoader, random_split

# Split your dataset into members / non-members
n = len(train_dataset)
members, nonmembers = random_split(train_dataset, [n//2, n//2])

# Run all attacks
results = auditml.audit(
    model,
    DataLoader(members),
    DataLoader(nonmembers),
    attacks=["mia_threshold", "model_inversion"],
)

# Access results
print(results.summary())
results["mia_threshold"].auc_roc   # → 0.641
results.is_vulnerable()               # → True
