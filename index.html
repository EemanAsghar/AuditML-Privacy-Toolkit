    Privacy Auditing
    for PyTorch Models

    One function call to audit your trained model for membership inference, model inversion, and attribute inference attacks. Know your model's privacy risk before deployment.

    Get Started → Read the Docs
    audit.py
    import auditml

    # Works with any trained PyTorch model
    results = auditml.audit(model, member_loader, nonmember_loader)

    print(results.summary())

    # Attack Accuracy AUC-ROC
    # mia_threshold 0.612 0.641
    # model_inversion 0.553 0.571
    # ⚠ Leakage detected — consider DP training

    # Open interactive HTML report in browser
    results.report("./report", open_browser=True)

    How it works

    From model to privacy report in three steps

    No config files. No YAML. Bring your model and data — AuditML handles the rest.

    01
    🧠

    Train your model

    Use any PyTorch architecture. If it's an nn.Module, it works.

    model = MyCNN()
    # ... your training loop
    02
    🔍

    Run the audit

    Pass your model and two loaders — members and non-members. Run all four attacks or pick specific ones.

    results = auditml.audit(
      model, members, nonmembers
    )
    03
    📊

    Get your report

    AUC-ROC, accuracy, TPR@1%FPR per attack. An interactive HTML report opens automatically in your browser.

    results.report("./report", open_browser=True)
    Privacy Attacks

    Four attacks. One unified API.

    Each attack exposes a different kind of privacy leakage. Run them all or pick only what you need.

    🎯
    Fast · seconds

    Threshold MIA

    Classifies members vs non-members by thresholding model confidence. The fastest attack — a strong privacy baseline in seconds.

    Type:White-box
    Signal:Loss / confidence
    👥
    Powerful · minutes

    Shadow Model MIA

    Trains shadow models to build an MLP membership classifier. The most powerful known membership inference attack.

    Type:Black-box
    Signal:Output distribution
    🖼️
    Visual · white-box

    Model Inversion

    Reconstructs training images via gradient descent in pixel space. Exposes what the model has memorised about each class.

    Type:White-box
    Signal:Gradients + TV loss
    🔍
    Sensitive attribute

    Attribute Inference

    Predicts sensitive group membership from softmax outputs — revealing whether the model leaks protected attributes.

    Type:Black-box
    Signal:Softmax outputs
    Get started

    Up and running
    in 60 seconds

    Install with pip and call auditml.audit() on your model. No API key, no signup.

    pip install auditml

    Requires Python 3.10+ and PyTorch 2.x.
    Read the full installation guide →

    example.py
    import auditml

    # Split dataset into members / non-members
    m, nm = auditml.split_loaders(train_dataset)

    # Run all attacks
    results = auditml.audit(model, m, nm)

    # Inspect
    results["mia_threshold"].auc_roc # → 0.641
    results.is_vulnerable() # → True

    # Save and reload
    results.save("results.json")
    r2 = auditml.AuditResults.load("results.json")
